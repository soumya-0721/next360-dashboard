⚠️ Firebase Setup Required for Session Tests
1. Go to Firebase Console → next360-dashboard
2. Left sidebar → Realtime Database → Create Database → Choose region → Start in test mode → Enable
3. Click Rules tab → Replace with:
{
  "rules": {
    "nxt360": {
      ".read": true,
      ".write": true
    }
  }
}
4. Click Publish
5. Left sidebar → Authentication → Get Started → Email/Password → Toggle ON → Save
6. Refresh this page and click "Run All Tests Again"
